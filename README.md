# AuralisMusic 3.0

Reproductor de música Android nativo basado en Kotlin, Jetpack Compose y Media3.

## Compilación automática

Cada push a `main` y cada ejecución manual del workflow **Build AuralisMusic APK** compila un APK debug y lo publica como artefacto llamado `AuralisMusic.apk`.

## APK

En GitHub: **Actions → Build AuralisMusic APK → última ejecución → Artifacts → AuralisMusic.apk**.
